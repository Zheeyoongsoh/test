# luvto Gelato Website Demo

A responsive static website built with plain HTML, CSS and JavaScript. No database or backend required.

## Files
- `index.html` — website structure and sample menu content
- `style.css` — colours, layout, responsive styling and animations
- `script.js` — mobile menu, flavour filters, reveal animations and footer year

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. An internet connection is needed for Google Fonts and the demo images.

## Before publishing
1. Replace sample prices, flavour names and descriptions with your actual menu.
2. Replace image URLs with your own product photos for the best brand consistency.
3. Update Instagram and WhatsApp links in `script.js`.
4. Add your shop address, opening hours and other real contact details.
5. Publish the folder using GitHub Pages, Netlify or another static hosting service.

The menu content is hard-coded in HTML. No customer data is collected or stored by this demo.
